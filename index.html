Monitoreo Biomédico Basado en IoT

Sistema de monitoreo remoto de signos vitales mediante tecnologías de Internet de las Cosas

Proyecto Arquitectura Sensores Resultados Contacto

Descripción General

Este proyecto desarrolla una plataforma de monitoreo biomédico basada en Internet de las Cosas (IoT) para la adquisición, transmisión y visualización remota de signos vitales.

📄 Descargar presentación completa (PDF)

Arquitectura del Sistema

El sistema integra sensores biomédicos, procesamiento digital, comunicación inalámbrica, almacenamiento de datos y una interfaz web para seguimiento remoto de pacientes.

Variables Monitoreadas

  • Frecuencia cardiaca
  • Saturación de oxígeno (SpO₂)
  • Temperatura corporal
  • Frecuencia respiratoria

Aplicaciones

  • Monitoreo remoto de pacientes.
  • Telemedicina.
  • Atención domiciliaria.
  • Seguimiento de enfermedades crónicas.
  • Investigación biomédica.
